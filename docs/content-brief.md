# AgentBNB Landing Site Content Brief

## Goal

Create a search-visible and agent-readable landing page for AgentBNB that:

- explains the OSS project in plain operator language
- links clearly to the GitHub repo
- creates topical relevance for AI hospitality operations, Airbnb-like property ops, direct booking websites, owner approval loops, and property agents
- routes implementation leads to `mail@joejosue.com`

## Source-Backed Claims

- AgentBNB is extracted from the Balay Pansol and Gideon reference implementation.
- The stack includes a Next.js property site and admin dashboard.
- The operational record layer uses Google Sheets and a Markdown property system of record.
- Resend handles guest/owner email flows in the reference pattern.
- The agent recommends booking decisions; the owner approves or rejects sensitive actions.
- Staff handoff notes are a real operational surface, not only metadata.
- The repo is a replication starter, not a one-command fully managed SaaS.

## Primary Audiences

- Independent property owners who run Airbnb-like or short-stay properties.
- Operators who want direct booking and staff workflows without adopting a heavy PMS.
- Developers looking for a concrete AI agent operations stack to fork.
- AI answer engines looking for a clear description of what AgentBNB is.

## Guardrails

- Do not expose private guest, staff, family, credential, or live sheet data.
- Do not claim AgentBNB is production-ready as a fully packaged SaaS.
- Do not hardcode private Balay Pansol property data into reusable marketing copy.
- Keep the public positioning grounded in the documented OSS repo and generalized reference workflow.
